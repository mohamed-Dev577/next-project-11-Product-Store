📌 وصف المشروع

مشروع متجر منتجات بسيط باستخدام Next.js وReact، يتيح للمستخدم إضافة المنتجات إلى قائمة وحذفها بسهولة.

🚀 التقنيات المستخدمة
Next.js
React
JavaScript
JSX
✨ المميزات
إضافة منتجات جديدة إلى القائمة.
منع إضافة المنتجات ذات الأسماء الفارغة أو التي تحتوي على مسافات فقط.
حذف المنتجات من القائمة.
إمكانية إضافة منتجات بنفس الاسم أكثر من مرة.
تفريغ حقل الإدخال تلقائيًا بعد إضافة المنتج.
تحديث قائمة المنتجات مباشرة باستخدام React State.
📚 المفاهيم التي تعلمتها
استخدام useState لإدارة الحالة.
التعامل مع الأحداث باستخدام onClick وonChange.
عرض العناصر باستخدام map().
حذف العناصر باستخدام filter().
استخدام trim() للتحقق من النصوص الفارغة.
تحديث المصفوفات باستخدام Spread Operator (...).
استخدام key عند عرض العناصر في React.

▶️ طريقة تشغيل المشروع
افتح مجلد المشروع في VS Code.
افتح Terminal داخل VS Code.

نفّذ الأمر التالي لتثبيت الحزم:

npm install

شغّل المشروع:

npm run dev

افتح المتصفح على:

http://localhost:3000

🧪 نتائج الاختبار
اجتاز المشروع الاختبارات الخمسة بنجاح.
إضافة المنتجات تعمل بشكل صحيح.
التحقق من الإدخال الفارغ يعمل بشكل صحيح.
حذف المنتجات يعمل بشكل صحيح.
حقل الإدخال يُفرّغ بعد الإضافة.
